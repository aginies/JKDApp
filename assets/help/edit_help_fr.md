# Aide du constructeur de combos

## Contrôles de l'espace de travail

| Bouton | Action |
|--------|--------|
| **+** | Ajoute une nouvelle étape indépendante (carte) à votre combo. |
| **A + B** | Fusionne la sélection avec un autre mouvement (exécutés en même temps). |
| **A -> B** | Enchaîne la sélection dans un flux séquentiel. |
| **Contre ⏎** | Ajoute une réponse défensive au mouvement sélectionné. |
| **Terminer** | Enregistre toute la séquence dans votre série. |
| **Annuler** | Abandonne la session de construction en cours. |

## Options de Carte

| Icône/Label | Signification |
|-------------|---------------|
| **G** | Côté Gauche |
| **D** | Côté Droit |
| **C** | Milieu (Direction) |
| **H** | Niveau Haut |
| **C** | Niveau Milieu |
| **B** | Niveau Bas |
| **D** | Feinte (Draw) |

## Labels de structure

- **CHAIN** : Mouvements effectués en séquence (l'un après l'autre).
- **SIMULTANEOUS** : Mouvements effectués en même temps.
- **CONTRE** : Une réponse défensive ou une contre-attaque.
