# Combo Builder Help

## Workspace Controls

| Button | Action |
|--------|--------|
| **+** | Add a new independent step (card) to your combo. |
| **A + B** | Merge selection with another move (performed at the same time). |
| **A -> B** | Chain selection into a sequential flow. |
| **Answer ⏎** | Add a defensive counter to the selected move. |
| **Finish** | Save the entire sequence to your series. |
| **Cancel** | Discard the current builder session. |

## Card Options

| Icon/Label | Meaning |
|------------|---------|
| **L** | Left side |
| **R** | Right side |
| **M** | Middle (Direction) |
| **H** | High level |
| **M** | Mid level |
| **L** | Low level |
| **D** | Draw / Feint |

## Structure Labels

- **CHAIN**: Moves performed in sequence (one after another).
- **SIMULTANEOUS**: Moves performed at the same time.
- **ANSWER**: A defensive response or counter-attack.
